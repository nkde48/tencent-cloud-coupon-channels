## 兑换码怎么兑换成代金券？

拿到兑换码后，按这个路径操作就行：

1. 登录腾讯云，进入**费用中心**。
2. 左侧选择**优惠管理 → 代金券**。
3. 点右上角的**兑换优惠券**。
4. 输入兑换码和验证码，确定。
5. 回到“待使用”列表，确认券已到账。

几个容易卡住的点：

- 微信卡券渠道的兑换码是**8位字母**；其他渠道的位数不一样，照着码原样输入即可，不用自己补位。
- 付款页面也能兑换：订单核对页上有“兑换优惠券”按钮，不必专门跳回费用中心。
- 只有账户创建者，或者有管理财务权限的协作者、子用户，才能兑换和使用代金券。子账号点不了兑换按钮，不一定是系统出问题。

## 为什么领了券却用不了？

多数情况是券和订单没匹配上。代金券的适用条件分好几个维度，任何一条不满足，结算时就看不到这张券：

- **适用产品不对**：指定产品券只能买对应产品；不指定产品券也有禁用清单，清单外的产品才能用。
- **购买时长超限**：券限定0–3个月时，买1年或3年的订单就用不了。
- **没到金额门槛**：满100元可用的券，订单金额不够就不会出现。
- **活动订单不支持**：部分促销活动订单明确不支持用券，以活动规则为准。
- **券过期或余额用尽**：有效期不能延长；单次使用的券用一次就作废，剩余余额也不能再用。
- **订单类型不支持**：欠费不能抵扣，后付费产品开通时的冻结费用也不能抵扣。

还有一条最常被忽略：**一次支付只能用一张代金券**。账户里有五张券，结算时也只能用一张，做预算时别按叠加来算。

把券本身的几个维度拆开看，会更容易判断一张券适不适合你的订单：

| 维度 | 类型 | 对下单的影响 |
| --- | --- | --- |
| 适用产品 | 指定产品 / 不指定产品 | 前者只限具体产品，后者有禁用清单 |
| 金额门槛 | 无门槛 / 满X元可用 | 有门槛的按单次支付金额判断 |
| 使用次数 | 单次 / 多次 | 单次券用一次即“已使用”，余额不退 |
| 付费场景 | 预付费（新购、续费、升配）/ 后付费 | 不是每张券都全部支持，以券面规则为准 |

## 系统会自动替你选券，规则值得先弄懂

- 自动用券开关默认打开，覆盖自动续费、后付费结算等场景。想保住某张券，去费用中心单独关掉它的自动用券。

## 新用户和老用户，领券重点不一样

新用户优先看首单特惠，老用户优先看会员券和续费专区，两条线的优惠通常不通用。

新用户注册后，首单专享价往往比领券更直接：2024年双11期间，新用户2核2G3M云服务器是68元/年。这类专享价按账号计算首单资格，同一个人换个账号不一定能再享受。

老用户的重点在续费和升级：会员中心有等级专享券，续费专区常有折上折，2024年双11期间服务器续费低至3.9折起。续费属于预付费场景，代金券可用于续费订单。顺序上，先领券再续费，别反过来。

## 常见问题

**腾讯云优惠券和代金券是一回事吗？**
是。控制台统一叫代金券，平时说的优惠券、抵用券指的都是它。

**领到的券在哪里查看？**
费用中心 → 优惠管理 → 代金券。分为待使用、已使用、已过期三种状态，只有“待使用”的能抵扣费用。

**优惠券可以叠加使用吗？**
不能。一次支付只能使用一张代金券。

**券快过期了能申请延期吗？**
不能，有效期不可延长。快到期的券优先用掉，或者下单时手动选它。
